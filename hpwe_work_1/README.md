# Три этажа — управление освещением

Учебное приложение на **CustomTkinter**: один общий пульт на первом этаже
одновременно включает или выключает свет в трёх комнатах на разных этажах.
Автор: Юшков Владислав

## Принятое условие задания

На каждом из трёх этажей находится одна комната. На первом этаже расположен
пульт с группой из двух радиокнопок: «Свет выключен» и «Свет включён».
Выбор одной радиокнопки устанавливает общее состояние всех трёх ламп.
В этой реализации нет индивидуальных выключателей комнат.

Это первая задача про общее управление светом. Загадка про определение
соответствия трёх выключателей трём лампам относится ко второму заданию.

## Требования

- Python **3.10 или новее**, с поддержкой Tkinter.
- Графический рабочий стол: приложение открывает обычное окно.
- Интернет нужен при первоначальной установке зависимостей; затем приложение
  работает без сети. Изображения, сервер и база данных не требуются.

На Windows Tkinter обычно входит в установщик Python с python.org.
Проверить его наличие можно командой `python -m tkinter` — откроется тестовое окно.
На Linux при отсутствии Tkinter установи пакет `python3-tk` средствами своей системы.

## Быстрый запуск на Windows

Откройте PowerShell или терминал VS Code в папке `hpwe_work_1`:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py(если запускаете из той же репы, то просто python main.py)
```

Активировать виртуальное окружение не обязательно: команды напрямую используют
его Python. При следующем запуске достаточно только последней команды.
Если команды `py` нет, в первой строке используйте `python`.

### macOS и Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

## Управление

1. При запуске свет выключен во всех комнатах, счётчик показывает «Горит 0 из 3».
2. Выбери **«Свет включён»**: все три лампы загораются тёплым цветом,
   подписи меняются на «Свет включён», счётчик показывает «Горит 3 из 3».
3. Выбери **«Свет выключен»**: все три лампы гаснут.
4. Повторный выбор уже выбранного состояния ничего не инвертирует.

Когда окно активно, можно использовать клавиши **1** для включения и **0**
для выключения. Эти клавиши вызывают те же действия, что и радиокнопки.
Закрытие окна завершает программу; состояние между запусками не сохраняется.

Этажи показаны сверху вниз: 3 — спальня, 2 — кабинет, 1 — гостиная.
Пульт отдельно подписан «1 этаж». Изменение света заметно и по цвету ламп,
и по текстовым подписям. Окно можно увеличивать; минимальный размер ограничен,
чтобы элементы управления оставались видимыми.

## Тесты

В той же папке установите зависимости разработки и запустите pytest:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

На macOS/Linux вместо `.\.venv\Scripts\python.exe` используйте `.venv/bin/python`.

Тесты модели проверяют начальное состояние, включение и выключение всех этажей,
повторный выбор, последовательность переключений и отклонение неправильных
значений без изменения текущего состояния. Отдельно проверяется, что старый
снимок комнат остаётся неизменным.

Интеграционные тесты создают настоящее окно CustomTkinter и вызывают `invoke()`
у настоящих радиокнопок. Они проверяют связь выбора с моделью, счётчиком и
подписями всех комнат. Во время тестов окно скрыто. На Linux без переменной
`DISPLAY` GUI-тесты пропускаются, а тесты модели продолжают работать.
Ошибки самого интерфейса не скрываются и приводят к падению тестов.

Только логика, без создания окна:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_model.py -q
```

## Как работает код

### 1. Запуск — `main.py`

Функция `main()` создаёт объект `LightingApp` и вызывает `mainloop()`.
Это цикл обработки событий: программа ждёт кликов, нажатий клавиш и закрытия
окна. Условие `if __name__ == "__main__"` не даёт автоматически открывать окно
при импорте файла из другого модуля.

### 2. Состояние — `lighting/model.py`

`HouseLighting` хранит один признак `_is_on`: `False` — свет выключен,
`True` — включён. Метод `set_lights()` устанавливает этот признак. Он принимает
только логические значения; неправильные аргументы вызывают `TypeError`.

Свойство `rooms` возвращает три объекта `RoomState`: этаж, название комнаты
и состояние света. Все три получают состояние из одного `_is_on`, поэтому
они всегда переключаются вместе. `lit_count` считает включённые лампы.
`@dataclass(frozen=True)` делает снимок комнаты неизменяемым: интерфейс не
может случайно включить одну комнату отдельно от остальных.

### 3. Окно — `lighting/app.py`

`LightingApp` наследуется от `CTk` — главного окна CustomTkinter.
`_build_header()` создаёт заголовок и счётчик.
`_build_content()` создаёт панель управления и три карточки `RoomCard`.
Менеджер `grid` распределяет пространство при изменении размера окна.

`light_value` — общая переменная `IntVar` двух радиокнопок. У выключения
`value=0`, у включения `value=1`. При выборе кнопки библиотека записывает
её значение в эту переменную и вызывает `_apply_selection()`.
Метод переводит выбор в `bool`, обновляет модель и вызывает `_render()`.

`_render()` берёт состояния комнат из модели и передаёт их карточкам,
обновляет счётчик и общую подпись. `RoomCard.render()` меняет текст, цвета
лампы и её окружения. Лампа состоит из вложенных `CTkFrame` с закруглениями:
никакие внешние фотографии или файлы иконок не загружаются.

Поток данных:

```text
Выбор радиокнопки → IntVar → _apply_selection()
→ HouseLighting.set_lights() → _render() → три комнаты и счётчик
```

Логика вынесена из интерфейса, чтобы её можно было читать и тестировать
без открытия окна. Приложение не запускает фоновых потоков и не использует
ожидания `sleep`, поэтому обработка действий не блокируется.

## Если не запускается

- `No module named customtkinter`: установите `requirements.txt` тем же Python,
  которым запускаешь `main.py`. В командах выше это Python из `.venv`.
- `No module named pytest`: установите `requirements-dev.txt`.
- `No module named tkinter`: добавьте поддержку Tcl/Tk в установку Python.
- Ошибка отсутствия дисплея: запускай приложение в графической сессии,
  а не на сервере без рабочего стола.
